# HireFlow bugfix — 2026-09-28

## Fixed issues reported during local run

### 1. Mongoose seed crash: `TypeError: next is not a function`

`backend/src/models/Job.js` used a callback-style `pre('validate', function(next) { ... next(); })` hook. The project uses Mongoose 9, where this hook is implemented using the synchronous/Promise-style middleware form here.

The hook is now:

```js
schema.pre('validate', function () {
  if (this.minSalary != null && this.maxSalary != null && this.maxSalary < this.minSalary) {
    this.invalidate('maxSalary', 'Maximum salary must be >= minimum salary');
  }
});
```

The salary rule is preserved while removing the invalid `next()` call.

### 2. Vite/JSX dependency scan error

`frontend/src/pages/public/JobDetailsPage.jsx` contained a numeric JSX attribute written as `rows=6`.

It is now `rows={6}`.

A source scan was also run to check for raw numeric JSX attributes of common DOM props such as `rows`, `cols`, `maxLength`, `minLength`, `size`, `tabIndex`, `width`, `height`, `colSpan`, and `rowSpan`.

Result: **0 matches**.
