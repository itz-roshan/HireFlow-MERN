# HireFlow UI/UX Recheck

- Heading font: Plus Jakarta Sans; body font: DM Sans, with system fallbacks.
- Primary CTA uses explicit white text in its default, hover and focus states.
- Hero uses restrained gradient, grid texture, glows and floating cards rather than heavy motion.
- Search bar has clear two-field hierarchy and keyboard focus treatment.
- Cards use consistent radius, border, spacing and shadow tokens.
- Dashboards use reusable StatCard, table, status-pill and empty-state components.
- Profile area visually prioritizes photo, name, headline and completion progress.
- Resume replacement is presented as a distinct document action.
- Notification bell is a first-class navigation control with an unread badge.
- Mobile navigation collapses and dashboard/sidebar content becomes horizontally scrollable where needed.
- `prefers-reduced-motion` disables decorative animations.
