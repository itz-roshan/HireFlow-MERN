4. NON-NEGOTIABLE QUALITY RULE
====================================================

Never hide an error.

Never show only:

"Validation failed"

Instead show the exact reason.

Examples:

"Full name must be at least 2 characters."

"Please enter a valid email address."

"Password must contain at least 8 characters."

"Passwords do not match."

"Please select whether you are looking for work or hiring."

"Resume must be a PDF smaller than 5 MB."

"MongoDB is not reachable. Start MongoDB or check MONGODB_URI."

"Unable to save profile. Please try again."

All API errors must preserve useful information.

5. ERROR RESPONSE CONTRACT
====================================================

  "code": "STABLE_ERROR_CODE",

  }
}

Frontend must map fieldErrors to the correct form fields.

Do not display raw database errors.

Do not display stack traces to users.

Do not show undefined/null/technical error objects in UI.
